Um desafio clássico de memória ambientado no universo sombrio do Cavaleiro das Trevas. Teste sua concentração e velocidade para provar que você é digno de entrar na Batcaverna!

## 📋 Sobre o Projeto
Este projeto foi desenvolvido para colocar em prática conceitos fundamentais de desenvolvimento web, utilizando uma das maiores figuras da cultura pop como tema central.

### 🛠️ Tecnologias Utilizadas
* **HTML5**: Estruturação semântica das páginas de login, jogo e pós-jogo.
* **CSS3**: Estilização personalizada com foco na estética "Gotham", incluindo efeitos de rotação 3D nas cartas e design responsivo.
* **JavaScript**: Lógica principal do jogo, manipulação do DOM e gerenciamento de estado.

## ✨ Funcionalidades Principais
* **Sistema de Login**: O jogador insere seu nome para personalização, com validação de entrada que habilita o botão apenas após 3 caracteres.
* **Embaralhamento Dinâmico**: Cada partida é única graças à lógica de embaralhamento aleatório das cartas ao carregar o jogo.
* **Cronômetro em Tempo Real**: Monitora quanto tempo o jogador leva para encontrar todos os pares.
* **Design Responsivo**: Interface adaptada para uma experiência fluida tanto em desktops quanto em dispositivos móveis.
* **Feedback Visual**: Cartas encontradas ficam desativadas e esmaecidas, facilitando a visualização do progresso.
